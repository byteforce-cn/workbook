# Internationalization (i18n)

`@byteforce/workbook` has built-in i18n support for all UI strings, with comprehensive coverage of form controls, navigation, and accessibility labels.

## Setting the Locale

```tsx
// Via DocumentRenderer
<DocumentRenderer workbook={myWorkbook} locale="zh-CN" />

// Via SimpleForm
<SimpleForm fields={fields} locale="zh-CN" />
```

## Default Text Language

Built-in UI copy (button labels, step navigation, validation hints, a11y
labels) falls back to **Chinese (`zh-CN`)** when neither the configured locale
nor the workbook's i18n dictionary provides a translation. To render the
interface in English — or any other language — supply translation resources
(see below) for the desired locale.

## Built-in i18n Keys

The workbook provides translations for all built-in UI strings:

| Key | Used for | zh-CN default | en |
|-----|----------|---------------|----|
| `workbook.form.submit` | Submit button | 提交 | Submit |
| `workbook.form.reset` | Reset button | 重置 | Reset |
| `workbook.steps.previous` | Previous step | 上一步 | Previous |
| `workbook.steps.next` | Next step | 下一步 | Next |
| `workbook.steps.label` | Steps ARIA label | 步骤 | Steps |
| `workbook.tabs.label` | Tabs ARIA label | 选项卡 | Tabs |
| `workbook.repeat.add` | Add row | 添加 | Add |
| `workbook.repeat.remove` | Remove row | 删除 | Remove |
| `workbook.select.placeholder` | Select placeholder | 请选择 | Select... |
| `workbook.readonly.empty` | Empty value in read-only text mode | — | — |
| `workbook.boolean.true` | Boolean true in read-only text mode | 是 | Yes |
| `workbook.boolean.false` | Boolean false in read-only text mode | 否 | No |

Tag-selector affordances (`移除标签 …` / `新增…`) are rendered from the field
label, not from i18n keys.
| `readonly.empty` | Empty value in read-only text mode | — | — |
| `boolean.true` | Boolean true in read-only text mode | 是 | Yes |
| `boolean.false` | Boolean false in read-only text mode | 否 | No |

## Providing Custom Translations

Pass custom translation resources via the i18n dictionary:

```tsx
import { DocumentRenderer } from "@byteforce/workbook";

const i18nResources = {
  "zh-CN": {
    "workbook.form.submit": "保存",
    "workbook.form.reset": "清空",
  },
  en: {
    "workbook.form.submit": "Save",
    "workbook.form.reset": "Clear",
  },
};

<DocumentRenderer
  workbook={{
    ...myWorkbook,
    i18n: i18nResources, // { [locale]: { [key]: text } }
  }}
  locale="zh-CN"
  fallbackLocale="en"
/>
```

## Resolving Text Programmatically

Use the core i18n utility for programmatic text resolution:

```ts
import { resolveI18nText, resolveBuiltInText } from "@byteforce/workbook/core";

// `resolveI18nText` resolves the `@:key` reference syntax used in the schema:
const label = resolveI18nText("@:workbook.form.submit", "zh-CN", i18nResources);
// "保存"

// `resolveBuiltInText` looks up a built-in key and falls back to a default:
const submit = resolveBuiltInText("workbook.form.submit", "zh-CN", i18nResources, "en", "提交");
// "保存"
```

## Adding Custom i18n Keys

Register custom keys in your schema:

```json
{
  "i18n": {
    "zh-CN": {
      "myField.label": "自定义字段",
      "myField.placeholder": "请输入内容"
    },
    "en": {
      "myField.label": "Custom Field",
      "myField.placeholder": "Enter content"
    }
  }
}
```

Then reference them from any label/title with the `@:` prefix:

```json
{
  "name": "customField",
  "label": "@:myField.label"
}
```

The fallback locale is the `fallbackLocale` prop (`"en-US"` by default), not a
schema field — see [Locale Fallback](#locale-fallback) below.

## Locale Fallback

When a translation is missing in the current locale, `resolveI18nText` falls
back to:

1. The dictionary entry for the `fallbackLocale` prop (`"en-US"` default)
2. For built-in strings, the Chinese default passed by the renderer
3. The raw `@:key` string, so a missing translation is visible instead of blank

## Using with React Context

For dynamic locale switching:

```tsx
import { DataProvider, WorkbookRuntimeProvider } from "@byteforce/workbook/react";

function App() {
  const [locale, setLocale] = useState("zh-CN");

  return (
    <select value={locale} onChange={(e) => setLocale(e.target.value)}>
      <option value="zh-CN">中文</option>
      <option value="en">English</option>
    </select>
    <DocumentRenderer workbook={myWorkbook} locale={locale} />
  );
}
```
