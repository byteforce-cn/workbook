# Changesets

Hello and welcome! This folder has been automatically generated by
[`@changesets/cli`](https://github.com/changesets/changesets), a build tool
that works with your package manager to bump versions in a multi-package repo,
and generate changelogs.

Add a changeset for any user-facing change:

```bash
pnpm changeset
```

Then describe the change and pick the semver bump (major / minor / patch).
Run `pnpm changeset status` to review pending changesets.
